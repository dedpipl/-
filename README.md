# Учебная платформа

Демонстрационное Angular-приложение для индивидуального задания.

## Запуск
1. Установите Node.js LTS.
2. Распакуйте архив и откройте папку `uchebnaya-platforma` в VS Code.
3. Откройте терминал VS Code (`Терминал → Новый терминал`).
4. Выполните:
   ```bash
   npm install
   npm start
   ```
5. Откройте адрес, который покажет Angular CLI (обычно `http://localhost:4200`).

## Что реализовано
- Курсы, уроки, тесты, результаты и панель преподавателя.
- Следующий урок открывается после завершения теста предыдущего урока.
- Вопросы с одним и несколькими ответами; для множественного выбора требуется точное совпадение набора.
- Автосохранение ответов в `localStorage`.
- Таймер 20 минут, остаток считается по сохранённому `expiresAt`.
- Seed сохраняется в Attempt, порядок вопросов восстанавливается.
- Завершение попытки идемпотентно: повторное нажатие не создаёт второй результат.
- Signals для состояния, computed для статистики.
- RxJS `debounceTime` и `switchMap` для поиска.
- Reactive Forms и групповой валидатор на форме курса.
- PrimeNG подключён в конфигурации приложения.

## Важное замечание для защиты
Это учебная демонстрация без отдельного backend. Данные хранятся в браузере через `localStorage`, поэтому они не синхронизируются между устройствами и не защищены от изменения пользователем. `HttpClient` подключён; `searchCourses()` показывает точку подключения API `/api/courses/search`, а поиск в демонстрации работает по локальным данным. Для промышленной версии нужен сервер, который атомарно проверяет `expiresAt`, фиксирует seed и не допускает повторное создание результата.

## Приёмочные сценарии
1. Для правильного набора `['A','C']` выбор `['A']` и `['A','C','D']` не совпадает и даёт 0; точный набор даёт полный балл. Та же логика находится в `DataService.finish()`.
2. `expiresAt` создаётся один раз при начале попытки. При повторном открытии активная попытка возвращается без изменения срока. Таймер вычисляет остаток через разницу с текущим временем.
3. `finish()` сначала проверяет статус Attempt и наличие уже созданного результата. Повторное завершение возвращает существующий результат.

## Вопрос для отчёта
Автосохранение выполняется непосредственно при изменении ответа: компонент вызывает метод DI-сервиса, сервис обновляет signal и сохраняет состояние. Таймер создаётся один раз при создании компонента, использует `expiresAt`, а `ngOnDestroy()` очищает интервал. Поэтому при уничтожении страницы таймер не остаётся работать, а при повторном открытии создаётся одна новая подписка/интервал для текущего экземпляра компонента. Для потоков RxJS в долгоживущих компонентах следует применять `takeUntilDestroyed()`.
